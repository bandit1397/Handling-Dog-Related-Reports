# 개 신고 현장 가이드

지구대 경찰관이 개 관련 신고 현장에서 휴대폰으로 열어 **상황 → 세부 사례 → 적용법조·처리방향**을 바로 찾는 웹앱입니다.

- 앱 주소: https://bandit1397.github.io/Handling-Dog-Related-Reports/
- 휴대폰에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다. 한 번 열어 두면 전파가 약한 곳에서도 볼 수 있습니다.
- 법령은 국가법령정보센터 현행 원문과 대조했습니다(동물보호법 2026.7.7., 경범죄 처벌법 2026.10.2. 시행본 기준). 현장 참고용이며 최종 판단은 법령 원문과 관서 방침을 따릅니다.

## 내용 고치는 방법

GitHub 웹사이트에서 바로 고칩니다. 저장(Commit changes)하면 1~2분 뒤 앱에 반영됩니다.

| 하고 싶은 일 | 방법 |
|---|---|
| 사례 내용 고치기 | `cases` 폴더 → 상황 폴더 → 사례 파일 열기 → 연필 아이콘 → 고치기 → **Commit changes** |
| 사례 추가 | 상황 폴더에서 **Add file → Create new file** → [`cases/_양식.md`](cases/_양식.md) 내용을 복사해서 채우기 |
| 사례 삭제 | 사례 파일 열기 → 오른쪽 위 `…` → **Delete file** |
| 사진 첨부 | `images` 폴더에서 **Add file → Upload files** → 사례 파일의 `## 사진` 아래에 `- images/파일이름.jpg \| 설명` 추가 |
| 홈 화면 "현장 핵심" | [`home.md`](home.md) 고치기 |
| 상황 설명(목록 위 안내) | 상황 폴더의 `_상황.md` 고치기 |
| 법령 조문 | [`laws`](laws) 폴더의 파일 고치기 |
| 되돌리기 | 파일 열기 → **History** → 이전 내용 확인 후 다시 고치기 |

앱의 사례 화면 맨 아래 **"GitHub에서 이 사례 수정"** 을 누르면 해당 파일의 수정 화면이 바로 열립니다.

## 사례 파일 쓰는 법

```
---
제목: 2m 목줄을 했으나 줄을 놓쳐 행인 상해
판정: 검토
원문대조: 완료
검색어: 줄 놓침, 놓쳤다, 갑자기 뛰어
---

## 적용법조
- 형법 제266조 과실치상 | 500만원 이하 벌금, 구류 또는 과료 | 반의사불벌

## 현장 확인
- 줄 길이가 2m 이하였는지(실측)
- 피해자 처벌 의사

## 처리방향
법정 안전조치 위반이 아니면 과실치상을 검토합니다.

## 참고
(필요할 때만)

## 사진
- images/diagrams/bite-flow.svg | 개물림 판단 순서
```

- **판정**은 `형사` · `위반` · `검토` · `적용곤란` · `적법` · `참고` 중 하나
- **원문대조**는 법령 원문과 맞춰 봤으면 `완료`, 해석이 남았으면 `일부 확인 중`
- **구분**(선택): 배설물처럼 한 상황 안에서 나눌 때 `구분: 대변` 처럼 씀
- **적용법조**는 한 줄에 `법조문 | 처벌 | 비고` 순서, 세로줄(`|`)로 나눔
- 파일 이름 앞 숫자(`01-`, `02-`)가 목록 순서입니다
- `**굵게**`, 목록(`- `), 표, 그림(`![설명](images/파일.svg)`)을 쓸 수 있습니다
- 본문에 `제10조제2항`, `같은 조 제3항제1호`, `시행규칙 제11조`처럼 조문을 쓰면 앱에서 자동으로 링크가 되어, 누르면 그 조문이 뜨고 해당 항·호가 강조됩니다. 법령 이름이 없으면 동물보호법으로 봅니다(다른 법이면 `형법 제266조`처럼 이름을 붙여 쓰세요)

저장한 뒤 형식이 틀리면 배포가 멈추고, **Actions** 탭에 무엇을 고쳐야 하는지 나옵니다(예: "판정 '위반함' 은(는) 쓸 수 없습니다"). 고쳐서 다시 저장하면 됩니다. 그동안 앱은 이전 내용으로 계속 동작합니다.

## 폴더 구성

```
cases/      상황별 폴더와 사례 파일 (.md)
laws/       조문 원문 (.md)
images/     맹견 사진(breeds), 도해(diagrams)
home.md     홈 화면 "현장 핵심"
site/       앱 화면 코드
tools/      build.py — 위 파일들을 모아 앱을 만듦
```

컴퓨터에서 미리 보려면: `python tools/build.py` 실행 후 `_site` 폴더에서 `python -m http.server` → http://localhost:8000
